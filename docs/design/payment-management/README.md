# Nơi lưu thiết kế hiện hành - payment-management

Chưa có bộ thiết kế được tạo trong lần thiết lập hướng dẫn này. Design Agent sẽ tạo tám tài liệu và thư mục PlantUML theo `.cursor/agents/design.md` sau khi đọc nguồn và hồ sơ phân tích.

```text
01-requirements-summary.md
02-architecture-design.md
03-detailed-design.md
04-api-contract.md
05-data-design.md
06-traceability-matrix.md
07-design-decisions.md
08-handoff-to-developer.md
diagrams/
    class.puml
    sequence.puml
    state-machine.puml
```

Đây là bộ thiết kế hiện hành, được cập nhật tại chỗ. Git lưu các phiên bản trước/sau review; không tạo thư mục phiên bản trong đường dẫn này. `component.puml` và các sơ đồ bổ sung chỉ tạo khi có nhu cầu rõ ràng.

Mọi phần bị chặn bởi vấn đề nguồn phải có mã liên kết, phương án và trạng thái. Khi mở review, lưu commit trước rồi tạo hồ sơ trong `docs/reviews/payment-management/Rxxx/`. Không coi README này là bộ thiết kế lần chạy đầu.
